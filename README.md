# A01_5512_hrk25001
Doing my first assignment for OPIM 5512 Data Science using Python

Assignment Overview

The purpose of this assignment is to practice using GitHub and Python while working with the California Housing dataset. The code loads the dataset, creates a boxplot to visualize the distribution of the selected data, and saves the resulting figure as a PNG file.

Dataset

This project uses the California Housing dataset provided by scikit-learn. The dataset contains information about housing districts in California, including variables such as median income, housing age, average rooms, population, and median house value.

Tools and Libraries
Python
Pandas
Matplotlib
Scikit-learn
GitHub / GitHub Desktop

How to Run
First, install the required Python packages using the requirements.txt file:
py -m pip install -r requirements.txt
Then, run the Python script from the project directory:
py src/boxplot.py

The script loads the California Housing dataset, creates the boxplot, and saves the figure in the figs folder.

Expected Output
After running the script, the following file will be created:
figs/boxplot.png
This image contains the boxplot generated from the California Housing dataset.

Repo Structure
